## 🧭 Repository Idea (New & Distinct)

This repository — **KageLedger** — is not a rehash of a trainer setup page. It is a **narrative-driven save-state companion** for open-world stealth adventures. Instead of focusing on "changing numbers," KageLedger treats your game profile like a **living ledger**: every stat, inventory slot, and skill node is a *line item* that you can annotate, snapshot, and roll back.

Where the original context (a trainer setup) was purely about installing a binary, KageLedger is about **profile auditing and continuity**. It answers a different question: *"If I reshape my journey, can I always return to the road I came from?"*

Think of it as a **library card for your saved worlds** — you borrow alternate versions of your character, then return the book exactly as you found it.

> Inspired by stealth-genre trainers and setup wizards, but rebuilt from first principles around **reversibility, privacy, and clarity**.

## 🌒 Why KageLedger Exists

Most companion tools in this space are written as one-off scripts — brittle, silent, and indifferent to what happens after you close them. KageLedger was authored after observing a simple pattern: players experimenting with an open-world stealth title often regret a change **five minutes later** and have no clean way back.

So the design brief became:

- Treat every modification as a **journal entry**, not a mutation.
- Keep a **shadow copy** of the world state before anything is touched.
- Present the entire experience through a **window that feels like it belongs to the game**, not to a hacker's terminal.

That is the shape of KageLedger: a ledger, a ledger-keeper, and a promise of return.

## 📱 Responsive Control Surface

The companion window is built with a **fluid layout engine** that reshapes itself to whatever screen estate you offer. On a 4K monitor it spreads into a three-column command deck. On a narrow laptop display it folds into a single scrollable ribbon. The transition is animated smoothly, and no feature disappears — everything is simply repositioned.

This means the same build feels native on:

- Ultrawide curved monitors
- Standard 1080p laptops
- Small tablets running Windows
- Portable handheld gaming PCs running Windows 11

The control surface is *responsive* not just in size but in **priority**: less urgent panels tuck away when the window is compressed, leaving the snapshot controls front and center.

## 🧰 Getting Started (Setup Walkthrough)

This walkthrough assumes you already have KageLedger on disk.

1. **Launch the companion.** The onboarding wizard opens on first run.
2. **Choose a ledger directory.** Default is inside your Documents folder; you may relocate it.
3. **Set your default language.** System language is preselected.
4. **Grant the companion visibility** to your local game profile folder (read-only is enough for the tour).
5. **Create your first snapshot.** Name it something evocative — "Prologue," "Kage of the First Wood," anything meaningful to you.
6. **Annotate anything.** Add a note beside a value you've changed your mind about.
7. **Try the Diff Viewer.** Compare the snapshot against a fresh copy.
8. **Explore Quiet Mode.** Toggle it and verify notifications fade during a session.
9. **Set a support preference.** Choose your preferred channel.
10. **Done.** The wizard closes, and the ledger stays open for you.

There is **no command-line step** required for normal use. Everything is done through the graphical companion.

## 🗂️ Ledger Snapshots Explained

A **snapshot** is a frozen record of your current world state alongside a small metadata block:

- Timestamp
- Optional title
- Optional tags
- Author note
- Content hash (for integrity checking)
- Parent snapshot reference (for lineage tracking)

Snapshots are stored as flat files in your ledger directory, so you can back them up, move them, or archive them without any special export step. The companion reads them natively.

A snapshot can be:

- **Applied** — restore the recorded state into the active profile
- **Cloned** — turn into a sibling snapshot for a branching playthrough
- **Archived** — moved to cold storage so it stays out of the way
- **Retired** — deleted after a confirmation preview

## ❓ Frequently Asked Questions

**Does the companion need an internet connection?**
No. Core functionality is fully local. Only support chat and update checks reach out.

**Can I move my ledger to another computer?**
Yes. Copy the ledger directory, and the companion will recognize it instantly on the new machine.

**What happens if I forget my vault passphrase?**
The vault cannot be opened without it. Keep your passphrase somewhere you trust. This is a design decision, not an oversight — a vault that can be opened without its key isn't a vault.

**Will my saved campaigns be altered without my consent?**
Never. Nothing is applied to a profile until you explicitly press the apply control, and every apply is reversible.

**Does this work on non-Windows systems?**
The 2026.1 build is Windows-only. Other platforms are under evaluation but not yet scheduled.

**Is there telemetry?**
No telemetry. The optional update checker only queries a version endpoint and stores no identifying data.
